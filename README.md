# Курсовая работа школы программирования Skypro, специализация "Python разработчик"

## Описание
В папке src созданы модули содержащие следующие функции:

+ Модуль views содержит функции get_price_of_stock и get_currency_rate, get_data_for_json_about_currency, get_data_for_json_about_stocks. Функция get_price_of_stock принимает на вход имя акции и возвращает её актуальную цену. Запрос производится с сайта twelvedata.com. Функция get_currency_rate принимает на вход название валюты в виде USD или EUR и возвращает её курс по отношению к рублю. Функции get_data_for_json_about_currency и get_data_for_json_about_stocks принимают на вход путь к файлу JSON. Файл user_settings.json лежит в корне проекта и содержит название акций, по которым нужно узнать цену и название валют для получения текущего курса.
+ Модуль utils содержит функции get_time_period и get_welcome_of_time. Функция get_time_period принимает на вход дату в виде строки, в формате YYYY-MM-DD HH:MM:SS и возвращает времени в виде списка с двумя датами в виде строки в формате DD.MM.YYYY HH:MM:SS. За начало периода берётся начало месяца, по принятую функцией дату. Если дата — 20.05.2020, то функция вернёт [01.05.2020-20.05.2020]. Функция get_welcome_of_time возвращает приветствие в формате "???" , где ???— «Доброе утро» / «Добрый день» / «Добрыйвечер» / «Доброй ночи» в зависимости от текущего времени.
+ В модуле main формируется итоговая JSON строка в виде: {"greeting": "Добрый день", "currency_rates": [{"currency": "USD", "rate": 73.21 }, {"currency": "EUR", "rate": 87.08 }], "stock_prices": [{"stock": "AAPL", "price": 150.12 }, {"stock": "AMZN", "price": 3173.18 }, {"stock": "GOOGL", "price": 2742.39 }, {"stock": "MSFT", "price": 296.71 }, {"stock": "TSLA", "price": 1007.08}]}
